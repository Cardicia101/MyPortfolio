# Cardicia's GitHub Pages Portfolio

A static 2026 portfolio built with HTML, CSS and JavaScript, designed to publish directly with GitHub Pages.

## Included
- Modern responsive AI/software developer portfolio
- Projects, skills, certifications and education
- Certificate and diploma proof images
- Downloadable CV
- GitHub and LinkedIn links
- Contact links directly to LinkedIn
- SQL Server schema in `database/schema.sql` for a future backend

The Contact Me links open the LinkedIn profile directly. The `database/schema.sql` file is retained for the project database design.

## Publish
1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Go to Settings -> Pages.
4. Choose "Deploy from a branch".
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will publish the site at your GitHub Pages URL.

GitHub Pages may take a few minutes to publish after the first deployment.
